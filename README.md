# Spotify Listening History Dashboard

## 📊 Project Overview

This project analyzes Spotify listening history from **2019 to 2022** and presents the insights through an interactive **Tableau dashboard**.

The dashboard focuses on listening behavior, top artists, albums and songs, hourly streaming patterns, song audio features, and stream distribution by decade.

## 🛠️ Tools & Technologies

- Tableau
- CSV
- Data Analysis
- Data Visualization

## 📌 Dashboard Highlights

- **89,013** Streams
- **298,357** Minutes listened
- **7,514** Songs
- **2,307** Artists
- Top Artists
- Top Albums
- Top Songs by Streams
- Streams by Hour
- Song Audio Features
- Streams by Decade

## 🔍 Key Analysis

### Listening Patterns
Analyzes streaming activity by hour and identifies listening patterns across Night, Morning, Afternoon, and Evening.

### Top Artists, Albums & Songs
Highlights the most frequently streamed artists, albums, and songs.

### Song Audio Features
Analyzes musical characteristics including Valence, Energy, Danceability, Acousticness, Instrumentalness, Liveness, and Speechiness.

### Streams by Decade
Shows how listening activity is distributed across different music decades.

The objective is to transform Spotify listening-history data into meaningful visual insights and demonstrate practical **Data Analysis and Tableau Dashboarding skills**.
